# 1 Purpose  
This roadmap converts the Phase-One demo prototype into a **production-ready, multi-integration, multi-tenant platform**.  It details scope, epics, milestones, acceptance criteria, risks, and success metrics for **Phase Two (Q3 2025) → Phase Five (Q2 2026)**, with a spotlight on **Microsoft SharePoint** integration reaching feature-parity with Autodesk ACC, Procore, Primavera P6, and Bluebeam Studio.

# 3 Phase Detail  

## 3.1 Phase Two – Production Foundation (Q3 2025)

| Epic | User Story (INVEST) | Acceptance Criteria | Success Metric |
|------|---------------------|---------------------|----------------|
| **E-2.1 AuthN/AuthZ** | _“As an org admin I issue role-based invites so users only see authorised evidence links.”_ | • JWT + refresh, OIDC provider<br>• RBAC roles: Admin, PM, Reviewer, Viewer<br>• Protected `/evidence/:id` endpoint returns 403 without token | ≥ 99 % auth test pass |
| **E-2.2 Persistence Layer** | _“As a PM I expect my chat history to persist after logout.”_ | • Postgres schema migrated; no data loss<br>• Redis cache <50 ms read | p95 read latency < 60 ms |
| **E-2.3 API Gateway v1** | _“As an integrator I call documented REST endpoints for docs & compliance status.”_ | • OpenAPI v1 published<br>• 80 % unit test coverage | Contract tests green |
| **E-2.4 CI/CD Pipeline** | _“As a dev I want PR lint, typecheck, test & auto deploy to staging.”_ | • GitHub Actions matrix (Node 18/20)<br>• `main`→staging auto-deploy<br>• Slack notify | <10 min pipeline |

### Milestone Checklist  
- ⭐ **Beta 1 tag** (`v0.9.0`) pushed to staging  
- AuthN “happy path” validated with Postman collection  
- Synthetic load: 10k docs → pipeline under 5 min  

### Key Risks & Mitigation  
| Risk | Likelihood | Impact | Mitigation |
|------|-----------|--------|-----------|
| JWT token leakage | Low | High | Rotate secrets via Vault, OWASP penetration test |
| DB schema churn | Med | Med | ADR-004 “Schema‐versioning” + Liquibase scripts |

## 3.2 Phase Three – Integration Expansion (Q4 2025)

### Scope Δ  
Add full-fidelity connectors for **Autodesk ACC, Procore, Primavera P6, Bluebeam Studio, _and new Microsoft SharePoint_**.

### SharePoint Epic Breakdown  

| Epic | Description | Acceptance Criteria |
|------|-------------|---------------------|
| **SP-1 OAuth Flow** | Graph API auth with PKCE + refresh | • Login completes in <30 s • Token stored in encrypted vault |
| **SP-2 Drive/Item Sync** | Scan Sites/Drives → mirror docs | • Initial backfill ≤ 10 k files in <4 h • Delta queries every 5 min |
| **SP-3 Webhook Handler** | Subscribe to driveItem change | • Events processed <30 s • 0 missed events in chaos test |
| **SP-4 Version & Metadata** | Persist SP versions + tags | • UI shows version history • Metadata searchable in 2 sec |
| **SP-5 RBAC Mapper** | Map M365 ACL to Plexify roles | • Permissions mirrored within 60 s |
| **SP-6 Error & Throttle Mgmt** | Graph 429 / 5xx backoff | • Auto-retry exponential, max 5 • Circuit-breaker logs metric |
| **SP-7 Contract Tests** | Mock Graph endpoints | • 95 % lines covered • CI <3 min |

### Milestones  
1. **Connector SDK ready** (10-2025)  
2. **SharePoint smoke test** with sandbox tenant (11-2025)  
3. **Integration Showcase** demo (12-2025)

### Success Metrics  
- 99.9 % sync accuracy across 24 h  
- Evidence link resolves to SP item in ≤ 800 ms  
- Zero P1 incidents during 2-week soak

### Risks  
| Risk | Mitigation |
|------|------------|
| Graph API throttling | Batch + delta queries, adaptive retry |
| ACL complexity | Permissions mapper ADR + unit tests for edge cases |
